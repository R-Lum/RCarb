RCarb - Dose Rate Modelling of Carbonate-Rich Samples ![https://r-lum.github.io/RCarb](figures/Logo_RCarb.svg)\
===============================================================================================================

The package provides a dose rate modelling for carbonate-rich samples in
the context of trapped charged dating (e.g., luminescence dating)
applications.
